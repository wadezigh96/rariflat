# World Is Flat Hackathon — Rariflat

## Submission checklist

- [x] Concept renovated from existing agent marketplace work
- [x] Clear $wif usage (hire fees, spend caps, volume signals, stake-to-unlock)
- [x] Flywheel documented
- [x] Categories aligned with Robinhood Chain (Stock Tokens, $wif Yield, etc.)
- [ ] Live contracts on Robinhood Chain
- [ ] Real $wif transactions in demo
- [ ] Demo video
- [ ] Deployed frontend

## Judges path

1. Open the marketplace.
2. Filter by category (especially Stock Tokens or $wif Yield).
3. Compare two agents on rarity, restraint, and $wif volume.
4. Open hire modal → see spend cap in $wif, blast radius, shadow mode.
5. See how activity feeds back into rarity ranking (flywheel).

## Why this is rare

Most agent tools are either pure trading bots or simple dashboards.
Rariflat combines **decision-grade rarity signals**, **restraint as a first-class metric**, and a **$wif-native flywheel** on Robinhood Chain.
